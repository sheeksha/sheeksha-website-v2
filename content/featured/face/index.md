An end-to-end face verification system using a custom-trained Siamese Neural Network, with optional DeepFace integration for comparison. Built with FastAPI and React, the app performs face detection, image preprocessing, and real-time predictions. Deployed on Render and Netlify, the results show similar accuracy between the custom model and DeepFace, confirming the viability of the in-house solution.
