Using Sentinel-2 multispectral satellite imagery and deep learning techniques, this project evaluates several Convolutional Neural Network architectures (VGG-16, ResNet-50, DenseNet-121, MobileNet-V2, YOLOv11 and others) for reliable ship detection within the Exclusive Economic Zone of Mauritius. The workflow included image preprocessing, patch generation, model training, hyperparameter tuning, and performance evaluation using accuracy scores and confusion matrices. Geographic analysis was carried out using QGIS and the Haversine formula to estimate vessel travel distances across the EEZ.

This research demonstrates how deep learning can support maritime monitoring, surveillance, and environmental protection efforts.
