Using Sentinel-2 multispectral satellite imagery and deep learning techniques, this project evaluates several Convolutional Neural Network architectures (VGG-16, ResNet-50, DenseNet-121, MobileNet-V2, YOLOv11 and others) for reliable ship detection within the Exclusive Economic Zone of Mauritius.
